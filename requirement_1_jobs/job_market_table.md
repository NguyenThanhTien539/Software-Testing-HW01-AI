**Tóm tắt mô tả công việc:**
Vị trí Manual Tester Leader phụ trách phân tích yêu cầu, xây dựng Test Plan, Test Case, Test Script và thực hiện functional, integration, regression, performance testing. Công việc gồm kiểm thử API, database, UI, quản lý tiến độ test theo Sprint/dự án, theo dõi lỗi và phối hợp với BA, Developer để đảm bảo chất lượng sản phẩm trước khi nghiệm thu.

**Kỹ năng yêu cầu:**
Ứng viên cần tối thiểu 3 năm kinh nghiệm Tester/QA, hiểu quy trình kiểm thử và mô hình Agile/Scrum hoặc Waterfall. Yêu cầu biết viết Test Case, Checklist, Bug Report; sử dụng Jira, TestRail, Selenium, Postman hoặc JMeter; có kiến thức API testing, database testing, performance testing, SQL cơ bản và đọc hiểu tiếng Anh. ISTQB/CSTE, Automation Testing, CI/CD hoặc kinh nghiệm tài chính/ngân hàng là lợi thế.

**Phân tích tác động của AI:**
Tin tuyển dụng không đề cập trực tiếp đến AI, nhưng AI có thể hỗ trợ tạo checklist, phân tích requirement, gợi ý test case, sinh test script cơ bản, đọc log lỗi và viết báo cáo test. Tuy nhiên, Tester Leader vẫn cần trực tiếp quản lý tiến độ, đánh giá rủi ro, quyết định phạm vi regression và chịu trách nhiệm cuối cùng về chất lượng sản phẩm.
